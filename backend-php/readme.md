## راهنمای استفاده از بک‌اند PHP

همانطور که می‌دانید در محیط توسعه‌ی AI Studio برای پیش‌نمایش سریع از Node.js استفاده شده بود. اما در این پوشه (`backend-php`) کدهای لازم برای اجرا روی هاست اشتراکی یا سرور لینوکسی شما با PHP و MySQL قرار داده شده است.

## مراحل نصب و اجرا روی هاست اصلی:

1. **دیتابیس**:
   - وارد کنترل‌پنل هاست خود شوید و یک دیتابیس MySQL بسازید.
   - فایل `database.sql` در همین پوشه را در phpMyAdmin ایمپورت (Import) کنید تا جداول و داده‌های اولیه ایجاد شوند.

2. **فایل API**:
   - فایل `/api/index.php` را باز کنید.
   - اطلاعات دیتابیس (نام کاربری، رمز عبور، نام دیتابیس) را در متغیرهای `$host`, `$db`, `$user` و `$pass` تنظیم کنید.
   - این فایل عملیات CRUD (افزودن، ویرایش، حذف دسته‌ها و محصولات) و آپلود فایل را به درستی طبق استاندارد API مدیریت می‌کند.

3. **آپلود روی هاست**:
   - خروجی بیلد React (محتویات پوشه `dist`) را که دانلود کرده‌اید، در روت هاست خود (مانند `public_html`) آپلود کنید.
   - فایل `.htaccess` موجود در همین پوشه را منتقل کنید به محل اصلی که `dist` را گذاشتید یا درون پوشه `api` تا روتینگ APIها به فایل `api/index.php` هدایت شود. با این روش، آدرس‌هایی مانند `/api/products` توسط `api/index.php` پردازش خواهند شد. پیشنهاد ما این است که پوشه‌ی `api` و فایل `.htaccess` را دقیقاً کنار فایل `index.html` خروجی React (داخل `public_html`) قرار دهید.
   - همچنین برای کار کردن صحیح بخش آپلود، پوشه‌ای به نام `uploads` در روت بسازید و دسترسی آن را روی 755 (یا 777 در برخی هاست‌ها) تنظیم کنید.

4. **تغییر رمز عبور ادمین**:
   - ورود ادمین با چک کردن مستقیم اطلاعات از دیتابیس (بر اساس متد ایمن `BCRYPT`) کار می‌کند. 
   - برای تغییر رمز پس از دیپلوی، ما یک فایل کمکی به نام `hash.php` درون فایل‌های بک‌اند قرار داده‌ایم. این فایل را اجرا کنید، رمز دلخواهتان را وارد کنید تا کُد هش (Hash) شده‌ی آن را به شما تحویل دهد.
   - در نهایت آن هش را کپی کرده و در دیتابیس خود (درون محیط phpMyAdmin) در جدول `admins` روی فیلد `password_hash` جایگزین کنید تا رمز شما تغییر کند.

5. **تغییر آدرس API**:
   - توجه کنید که برنامه React به صورت پیش‌فرض آدرس نسبی (مثلا `/api/products`) را صدا می‌زند. چون شما پوشه `api` را روی همان دامنه آپلود می‌کنید، همه چیز بدون مشکل کار خواهد کرد.
