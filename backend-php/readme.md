# راهنمای نصب و استقرار (نسخه تجاری PHP / MySQL)

این پروژه دو بخش دارد:

1. **پیش‌نمایش توسعه (`server.ts`)** — فقط برای اجرای محلی و کار در AI Studio (Node.js + SQLite). **برای فروش استفاده نمی‌شود.**
2. **نسخه تحویل به مشتری (`backend-php/` + خروجی `release-cpanel/`)** — PHP 8+ و MySQL، مناسب هاست اشتراکی cPanel/DirectAdmin. **این همان نسخه‌ای است که روی سایت زنده اجرا می‌شود.**

---

## ۱. ساخت بسته تحویل

```bash
npm install
npm run package:php
```

پوشه `release-cpanel/` ساخته می‌شود و شامل موارد زیر است:

- `index.html` و `assets/` (فرانت‌اند کامپایل‌شده)
- `api/` (روتر، احراز هویت، سرویس تصویر و اعلان)
- `uploads/` (تصاویر WebP + `.htaccess` امنیتی)
- `database.sql` (ساختار جداول و ۱۲ محصول نمونه)
- `.htaccess` (مسیردهی API و SPA، مسدودسازی فایل‌های حساس)

> اگر سایت زیرمسیر است (مثل `domain.com/Menu/`)، قبل از build مقدار `VITE_BASE=/Menu/` را در `.env` بگذارید. برای نصب روی ریشه، `VITE_BASE=/` باشد.

---

## ۲. نصب روی هاست مشتری

1. **دیتابیس:** یک دیتابیس MySQL و کاربر بسازید، در phpMyAdmin دیتابیس مقصد را انتخاب کنید و `database.sql` را ایمپورت کنید.
   > ⚠️ اگر سایت شما از قبل منو و محصولات دارد، `database.sql` را دوباره ایمپورت **نکنید**؛ فقط فایل‌های برنامه را جای‌گزین کنید. (`database.sql` فقط برای نصب تازه است.)
2. **تنظیمات اتصال:** متغیرهای محیطی هاست را تنظیم کنید:
   - `DB_HOST`، `DB_NAME`، `DB_USER`، `DB_PASS`
   - `JWT_SECRET` (حداقل ۳۲ کاراکتر تصادفی)

   اگر `JWT_SECRET` تنظیم نشود، سرور یک کلید تصادفی در فایل `.jwt-secret.php` کنار پروژه می‌سازد (فایل با `.htaccess` مسدود شده است).
3. **آپلود:** محتویات `release-cpanel` را در پوشه‌ی مقصد آپلود کنید:
   - نصب زیرمسیر: `public_html/Menu/` ← آدرس سایت `domain.com/Menu/`
   - نصب روی ریشه: `public_html/`
4. **اولین ورود:** با `admin` / `admin123` وارد `/log` شوید و **بلافاصله رمز را از بخش «تنظیمات برند» عوض کنید.**

---

## ۳. قراردادهای مهم

- **واحد قیمت:** همه قیمت‌ها با واحد **هزار تومان** ذخیره می‌شوند. عدد `145` یعنی ۱۴۵٬۰۰۰ تومان. در UI به صورت «۱۴۵ هزار تومان» نمایش داده می‌شود. هنگام ایمپورت داده‌ی قدیمی، اگر قیمت‌ها کامل (مثلاً `145000`) بودند، بر ۱۰۰۰ تقسیم کنید.
- **توکن اعلان‌ها عمومی نیست:** `GET /api/settings` هرگز `notification_bot_token`، `notification_chat_id` و `notification_webhook_url` را برنمی‌گرداند. فرم پنل از `GET /api/admin/settings` (با توکن) استفاده می‌کند.
- **آپلود تصویر:** مرورگر تصویر را به WebP تبدیل می‌کند؛ سرور نوع واقعی فایل را از بایت‌های جادویی بررسی می‌کند. اگر ImageMagick روی هاست نصب باشد، فرمت‌های دیگر هم تبدیل می‌شوند.
