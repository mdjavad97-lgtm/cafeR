# راهنمای نصب و استقرار نسخه تجاری (ویژه هاست اشتراکی cPanel / DirectAdmin و سرور لینوکس)

این پروژه با معماری دوگانه استاندارد طراحی شده است:
1. **محیط پیش‌نمایش و توسعه ابری (`server.ts`):** صرفاً برای اجرای زنده در محیط پیش‌نمایش ابری (Node.js + SQLite) استفاده می‌شود.
2. **نسخه تحویل تجاری به مشتری (`backend-php` و خروجی `release-cpanel`):** یک بسته کاملاً مستقل، ماژولار و امن بر پایه **PHP 8+ و MySQL (PDO)** که بدون نیاز به Node.js مستقیماً روی هر هاست اشتراکی لینوکس (`public_html`) نصب می‌شود.

---

## ۱. نحوه ساخت پکیج یکپارچه تحویل به خریدار
برای اینکه خریدار هنگام نصب با فایل‌های محیط توسعه مواجه نشود، دستور زیر را اجرا کنید:
```bash
npm run package:php
```
با اجرای این دستور، پوشه **`release-cpanel/`** ساخته می‌شود که فقط شامل فایل‌های نهایی زیر است:
- فایل‌های کامپایل‌شده فرانت‌اند (`index.html` و `assets/`)
- پوشه ماژولار `api/` شامل:
  - `config/database.php`: تنظیمات اتصال امن PDO با غیرفعال‌سازی `EMULATE_PREPARES` (مقاوم در برابر SQL Injection)
  - `middleware/SecurityMiddleware.php`: احراز هویت مبتنی بر توکن امضاشده **JWT (HMAC-SHA256)** و هدرهای امنیتی
  - `services/ImageService.php`: بررسی بایت‌های جادویی تصویر (`finfo_file`)، حذف کامل کدهای مخرب احتمالی (Anti-Shell)، تغییر سایز خودکار به حداکثر `1080px` و **فشرده‌سازی خودکار به فرمت کم‌حجم WebP**
  - `index.php`: روتر اصلی API
- پوشه `uploads/` حاوی تصاویر بهینه‌شده `.webp` و فایل امنیتی `.htaccess` (که اجرای هرگونه اسکریپت PHP را در پوشه آپلود مسدود می‌کند).
- فایل `database.sql`: ساختار کامل جداول و ۱۲ محصول نمونه با مسیرهای `/uploads/*.webp`.

## ۲. مراحل نصب روی هاست مشتری (cPanel / DirectAdmin)
1. **ایجاد دیتابیس MySQL:**
   - در کنترل‌پنل هاست یک دیتابیس و کاربر MySQL بسازید و فایل `database.sql` را در `phpMyAdmin` ایمپورت کنید.
2. **تنظیم اطلاعات اتصال دیتابیس:**
   - فایل `api/config/database.php` را باز کرده و مشخصات `DB_NAME`، `DB_USER`، `DB_PASS` و کلید امضای `JWT_SECRET` را وارد نمایید.
3. **آپلود فایل‌ها:**
   - محتویات پوشه `release-cpanel` را مستقیماً در `public_html` آپلود کنید.
4. **تغییر رمز عبور و شخصی‌سازی برند کافه:**
   - با نام کاربری `admin` و رمز عبور اولیه `admin123` وارد آدرس `/log` شوید.
   - از داخل پنل مدیریت، روی دکمه **«تنظیمات برند و لوگو»** کلیک کنید تا نام کافه، لوگو، پالت رنگی و **رمز عبور جدید مدیریت** را به صورت امن و مستقیم تغییر دهید (نیازی به هیچ فایل جانبی مانند `hash.php` نیست).
